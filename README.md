# Кто ваш УИК — поиск УИК / первички / депутата

Статичный сайт без сборки и без сервера. Всё работает в браузере.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | страница |
| `styles.css` | оформление (есть тёмная тема и мобильная верстка) |
| `app.js` | поисковый движок (опечатки, сокращения, дома) |
| `data.js` | данные: 127 УИК, 1203 адресные записи |

## Как проверить локально

Дважды кликнуть по `index.html` — откроется в браузере и сразу будет работать
(данные вшиты в `data.js`, никакого `fetch` не требуется).

## Деплой на Vercel (самый простой путь)

1. Зайти на https://vercel.com → Add New → Project → **Deploy without Git**
   (или https://vercel.com/new → вкладка с загрузкой папки).
2. Перетащить туда всю папку `uik-site`.
3. Framework Preset: **Other**. Build Command: пусто. Output Directory: `./`
4. Deploy. Готово — получится адрес вида `имя.vercel.app`.

### Альтернативы

- **Vercel CLI**: `npm i -g vercel`, затем в папке `vercel --prod`.
- **GitHub Pages / Netlify Drop / Cloudflare Pages** — точно так же, без сборки.

## Как обновить данные

Данные собраны из двух документов:

- `Постановление от 07.04.2026 № 859.docx` — границы УИК (улицы и дома);
- `Привязка ПО к УИК 2023 (новая).docx` — первичные отделения и депутаты.

При новой редакции нужно перегенерировать `data.js` скриптом парсера
(`parse_all.py`, лежит вне папки сайта) — остальные файлы менять не надо.

## Логика поиска (кратко)

- можно писать без запятых и сокращений: `Ногинск самодеятельная 10`;
- понимает `г`, `город`, `пос`, `поселок`, `д`, `деревня`, `ул`, `улица`, `пер`, `мкр`, `СНТ` и т.д.;
- терпит опечатки: `самадеятелная` найдёт `Самодеятельная`;
- поиск по номеру УИК: ввести `1871`;
- **ничего не угадывает**: если дома нет в границах — ставится пометка
  «дома нет в списке», а не подбирается ближайший; при спорных случаях
  показываются все возможные участки с предупреждением.

- `jokes.js` — безобидные шутки-подписи к результатам (подбираются по улице / населённому пункту)
